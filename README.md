# Qadawi Journal — قضاوي

دفتر يوميات عربي يساعدك تتذكر يومك، تجد الكلمات المناسبة، وتحفظ تفاصيل حياتك.

**المنصة:** https://mq313qdu-ux.github.io/qadawi-journal/

## الخصوصية والبيانات

اليوميات والمرفقات محفوظة في IndexedDB على جهازك داخل المتصفح. لا يوجد حساب مطلوب أو تتبع أو إرسال تلقائي لمحتوى اليوميات. يعمل التطبيق دون اتصال بعد تحميله أول مرة، ويمكن تثبيته كتطبيق PWA.

احفظ نسخة JSON من مركز النسخ الاحتياطي دوريًا. بيانات كل عنوان موقع منفصلة؛ للانتقال من النسخة السابقة، صدّر نسخة JSON منها ثم استوردها في عنوان GitHub Pages. استخدام نفس المتصفح وحده لا ينقلها تلقائيًا.

## التشغيل المحلي

يتطلب Node.js 24 أو أحدث.

```sh
npm ci
npm start
```

افتح http://127.0.0.1:4173

## الفحص والنشر

```sh
npm run lint
npm run check
npm test
npm run build
```

ملفات التطبيق الجاهزة داخل `dist`. ينشر GitHub Actions هذا المجلد فقط بعد نجاح الفحوص، عند رفع تغييرات إلى `main`. إعداد GitHub Pages يستخدم المصدر **GitHub Actions**. مسارات الملفات نسبية لتعمل داخل عنوان المستودع.

اختبارات المتصفح الإضافية: `npm run test:browser`، مع توفر Playwright وMicrosoft Edge. تستخدم بيانات اختبار منفصلة.

اختبار حجم الأرشيف: `npm run test:scale`، باستخدام 3,000 يوم و3,000 موقف اصطناعي داخل سياق متصفح مؤقت. لا تستخدم هذه الاختبارات ملف المتصفح الشخصي أو عنوان المنصة المنشور.

دليل التصميم: [DESIGN.md](DESIGN.md). تقرير جودة المنتج والفحوص وحدودها: [QA-REPORT.md](QA-REPORT.md).

الخطوط مرفقة محليًا وتراخيصها داخل `dist/fonts`.

[تقرير الصقل والاختبارات وحدود الأجهزة](docs/FINAL_POLISH_2026_REPORT.md) · [قائمة المراحل الأربعين](docs/FINAL_POLISH_2026_CHECKLIST.md).
